
# Smart Canteen Ordering System

## Project Description
A system where students can view the canteen menu, add food to a cart, make digital payments, select pickup slots, and receive order confirmations.

## User Stories
1. As a student, I want to browse the menu to select food.
2. As a student, I want to add items to my cart to place an order.
3. As a student, I want to pay digitally to complete my order.
4. As a student, I want to select a pickup slot to collect food.
5. As a student, I want to receive order confirmation.
6. As a canteen manager, I want to update menu prices and availability.

## INVEST
Stories should be Independent, Negotiable, Valuable, Estimable, Small, and Testable.

## Sprint Plan
Sprint 1: Menu, cart, payment, and pickup slot.

Sprint 2: Order confirmation, payment failure testing, and menu management.

## Acceptance Criteria
- Menu displays items and prices.
- Cart total updates correctly.
- Failed payment displays an error.
- Unavailable pickup slots cannot be selected.
- Order confirmation displays an order ID.

## Definition of Done
A story is complete when acceptance criteria pass, testing is complete, documentation is updated, and the work is reviewed.

## Testing
1. Test menu browsing.
2. Test adding items to the cart.
3. Test payment failure.
4. Test pickup-slot conflicts.
5. Test order confirmation.
6. Report duplicate orders as a defect if reproduced.

## Sprint Review
Review completed stories, test results, and feedback from the canteen manager.

## Retrospective
What went well: Tasks were organized.

What to improve: Test failures earlier and improve estimation.
